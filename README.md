# House Prices — Advanced Regression Techniques

Учебный проект по машинному обучению на основе соревнования [House Prices — Advanced Regression Techniques](https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques).

**Цель проекта:** построить модель для прогнозирования стоимости жилой недвижимости (`SalePrice`) по 80 признакам, сравнить несколько семейств алгоритмов и выбрать решение с наилучшей обобщающей способностью.

В проекте реализован полный ML-пайплайн: от разведочного анализа данных (EDA) и предобработки до подбора гиперпараметров, кросс-валидации и формирования предсказаний для Kaggle.

## 1. Результаты проекта

Были исследованы линейные модели, деревья решений, ансамбли, градиентные бустинги, стекинг и нейронные сети.

По результатам экспериментов для финального сравнения были выбраны **CatBoost, MLPRegressor и Stacking D**.

| Модель | CV RMSE | Holdout RMSE | Holdout R² |
|---|---:|---:|---:|
| **Stacking D** | 0.121335 | **0.127306** | **0.913151** |
| CatBoost | **0.116511** | 0.129319 | 0.910384 |
| MLPRegressor | 0.116928 | 0.138420 | 0.897326 |

*RMSE рассчитан в логарифмической шкале `log1p(SalePrice)`.*

### Результаты Kaggle

После финального сравнения Stacking D и CatBoost были переобучены на полном тренировочном датасете.

| Модель | Kaggle Public RMSLE |
|---|---:|
| **Stacking D** | **0.12350** |
| CatBoost | 0.12459 |

**Финальной моделью выбран Stacking D**, объединяющий ElasticNet, RandomForest, LightGBM и CatBoost с метамоделью Ridge.

Несмотря на преимущество CatBoost на кросс-валидации, Stacking показал более низкую ошибку на Holdout и публичной части Kaggle Test.

## 2. Данные

Используется датасет соревнования Kaggle House Prices:

- `train.csv` — 1460 объектов с известной ценой продажи.
- `test.csv` — 1459 объектов без целевой переменной.
- `sample_submission.csv` — пример формата файла для отправки на Kaggle.

Целевая переменная — `SalePrice`.

Для стабилизации распределения целевой переменной и обучения моделей используется логарифмическое преобразование:

`y_log = np.log1p(SalePrice)`

После предсказания применяется обратное преобразование:

`SalePrice = np.expm1(y_pred_log)`

## 4. Установка и запуск

### Создание окружения

Для Windows PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m pip install -r requirements-boosting.txt
```

При необходимости запуска дополнительных экспериментов с PyTorch:

```powershell
python -m pip install -r requirements-torch.txt
```

### Воспроизведение финального решения

Из корневой папки проекта:

```bash
python run_all.py
```

Скрипт автоматически:

1. Загружает данные из `data/raw/`.
2. Считывает сохранённые гиперпараметры из `reports/`.
3. Выполняет предобработку данных.
4. Обучает CatBoost и Stacking D на всех 1460 размеченных объектах.
5. Формирует предсказания для Kaggle Test.
6. Сохраняет файлы `submission_catboost.csv` и `submission_stacking.csv` в корне проекта.

**Важно:** запуск `run_all.py` не требует повторного выполнения Optuna, GridSearchCV или исследовательских ноутбуков.

Модели обучаются заново, но используют уже найденные гиперпараметры.

### Запуск тестов

```bash
python -m pytest tests/ -v
```

Либо запустить тесты после обучения моделей:

```bash
python run_all.py --with-tests
```

## 5. Предобработка данных

Предобработка реализована в `src/features.py` с использованием `Pipeline` и `ColumnTransformer`.

Основные этапы:

- Исключение `Id` и `SalePrice` из признаков.
- Преобразование `MSSubClass` и `MoSold` в категориальные признаки.
- Заполнение пропусков в числовых признаках медианой.
- Создание индикаторов отсутствующих числовых значений.
- Обработка категориальных пропусков: отдельная категория `None` для признаков, где отсутствие объекта имеет смысл.
- Кодирование категорий через One-Hot Encoding.
- Применение StandardScaler для моделей, требующих масштабирования.

Предобработка выполняется внутри Pipeline, что позволяет избежать утечки данных при кросс-валидации.

## 6. Обучение и подбор моделей

### Линейные модели

Исследованы:

- LinearRegression
- Ridge
- Lasso
- ElasticNet

Для подбора гиперпараметров использовался GridSearchCV.

Лучший результат показал ElasticNet: **CV RMSE = 0.1384**.

### Деревья решений и ансамбли

Исследованы:

- DecisionTreeRegressor
- RandomForestRegressor
- ExtraTreesRegressor

Лучший результат показал RandomForest: **CV RMSE = 0.1403**.

### Градиентные бустинги

Исследованы:

- AdaBoost
- GradientBoosting
- HistGradientBoosting
- XGBoost
- LightGBM
- CatBoost

Для подбора гиперпараметров использовалась Optuna.

Лучший результат показал CatBoost: **CV RMSE = 0.1165**.

### Нейронные сети

Для решения задачи использовался `MLPRegressor`.

В ходе экспериментов исследовались оптимизаторы SGD с Momentum, Adam и L-BFGS, а также различные архитектуры и параметры регуляризации.

Лучшая конфигурация:

- Архитектура: `(128, 32, 64)`.
- Оптимизатор: SGD с Momentum.
- Learning rate: `0.008706`.
- Momentum: `0.9079`.
- Batch size: `16`.
- L2-регуляризация: `alpha = 0.0685`.

Лучший результат: **CV RMSE = 0.1169**.

### Stacking

Исследовались различные комбинации базовых моделей, объединённых с помощью StackingRegressor.

В финальную конфигурацию вошли:

- ElasticNet
- RandomForest
- LightGBM
- CatBoost

В качестве метамодели использовалась Ridge Regression.

Именно Stacking D показал лучший результат на Holdout и Kaggle Public Leaderboard.

## 7. Валидация и оценка качества

Для построения и оценки моделей использовались:

- **Train** — 80% размеченных данных для разработки и подбора моделей.
- **5-Fold Cross-Validation** — оценка качества моделей и подбор гиперпараметров.
- **Holdout** — 20% размеченных данных для финального независимого сравнения.
- **Kaggle Test** — скрытая тестовая выборка для проверки на платформе.

Основная метрика при локальной оценке — RMSE для `log1p(SalePrice)`.

Для Kaggle используется RMSLE.

После финальной оценки выбранные модели переобучались на всех доступных размеченных данных.

## 8. Воспроизводимость экспериментов

Проект разделён на две части.

**Исследовательская часть**

Ноутбуки содержат EDA, сравнение алгоритмов, кросс-валидацию, GridSearchCV, эксперименты Optuna и анализ результатов.

Повторное выполнение всех исследовательских ячеек необязательно и может потребовать значительного времени.

**Финальный Pipeline**

`run_all.py` использует сохранённые конфигурации моделей и автоматически формирует итоговые предсказания.

Таким образом, для получения Kaggle Submission достаточно установить зависимости и выполнить:

```bash
python run_all.py
```

## 9. Итоговые выводы

В ходе проекта были исследованы разные подходы к регрессии на табличных данных — от линейных моделей до градиентных бустингов и нейронных сетей.

Подбор гиперпараметров и корректная предобработка позволили значительно улучшить качество моделей.

CatBoost и MLPRegressor продемонстрировали лучшие результаты на кросс-валидации, однако на отложенной выборке лидером стал Stacking D.

Финальное решение достигло **0.12350 RMSLE на Kaggle Public Leaderboard**.

Проект демонстрирует полный цикл разработки ML-решения: анализ данных, построение признаков, обучение, настройку моделей, независимую оценку качества и воспроизводимое формирование предсказаний.
